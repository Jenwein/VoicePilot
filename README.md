# VoicePilot
七牛云第二批议题二，桌面语音助手

## 部署方式

```bash
git clone --recursive https://github.com/Jenwein/VoicePilot.git
```

--or

```bash
git clone https://github.com/Jenwein/VoicePilot.git
git submodule update --recursive --init
```
然后
```bash
cd ../
run scripts/Win-GenProjects.bat
run VoicePilot.sln
```
