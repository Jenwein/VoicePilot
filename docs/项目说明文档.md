# VoicePilot 桌面语音助手项目说明文档

## 1. 功能规划与优先级

### 核心架构
桌面语音助手的三大核心模块：
1. **语音交互层**：ASR/STT实现语音转文本，TTS实现语音合成
2. **需求理解层**：通过LLM实现Function Calling，构建Agent系统，支持历史会话与上下文理解
3. **执行回复层**：根据Function Calling结果执行相应工具，返回执行结果

### 功能优先级分级

#### 🔴 高优先级（本次MVP已实现）
- **基础语音交互闭环**
  - 完整的"听-想-做-说"流程
  - 语音识别 → 自然语言理解 → 任务执行 → 语音合成
- **连续对话能力**
  - 支持多轮对话的上下文理解
  - 维护会话历史状态
- **任务执行能力**
  - 原子任务：单一明确指令（如"打开记事本"、"调高音量"）
  - 复杂任务：多工具依赖调用、并行工具执行
- **用户界面**
  - 简洁界面设计
  - 3D助手形象，根据不同阶段显示状态反馈

#### 🟡 中优先级（后续版本迭代）
- **高级任务处理**
  - 复杂任务分解与执行
  - 多步骤指令处理（如"找一首安静的纯音乐，然后打开Word"）
- **系统信息查询**
  - 时间查询、系统状态查询
  - 磁盘空间、性能监控等
- **架构优化**
  - 可扩展的能力接口
  - 工具添加与提示词优化机制

#### 🟢 低优先级（长期规划）
- **个性化设置**
  - 可配置音色/语速选择
  - 用户偏好记忆
- **完善的用户界面**
  - 图形化设备选择
  - 唤醒词自定义设置
  - 指令列表管理界面

### 本次开发计划
专注于MVP开发，重点实现Agent系统，确保产品具备多轮对话和复杂任务处理能力。

## 2. 实现挑战与应对策略

### 主要技术挑战

#### 挑战一：Agent逻辑架构设计
**问题描述**：如何构建有效的Agent系统来处理多轮会话和多工具调用

**应对策略**：
- 深入调研AutoGPT、LangChain等成熟框架
- 采用当前的Agent模型架构（[流程示意图链接]）
- 建立标准化的Function Calling协议

#### 挑战二：技术选型与语言选择
**问题描述**：从C++转向更适合业务逻辑处理的语言选择

**遇到的问题**：
- C++在网络请求和字符串处理方面开销较大
- 初期C++和Python通过命令行交互，遇到JSON和CMD字符编码问题

**解决方案演进**：
1. **初期**：C++控制台调用Python脚本
2. **考虑过**：gRPC、网络通信、纯C++实现
3. **最终方案**：CPython + pybind11
   - 实现嵌入式双向调用
   - 更好的架构隔离
   - 提升稳定性和效率

## 3. LLM模型选型与对比

### 选择的模型
**Google Gemini 系列模型**（主要使用 Gemini 2.5 Flash）

### 技术实现
- 在`ai_service.py`中集成Google genai SDK
- 基于Gemini API构建核心AI能力


### 选择理由
1. **开发体验**：API文档清晰，集成简单
2. **成本控制**：相比其他方案成本更低
3. **能力匹配**：编码和逻辑处理能力符合项目需求
4. **个人熟悉度**：长期使用Gemini网页版，了解其能力特点

## 4. 未来功能规划

### 规划一：AI自驱动创造性
**功能描述**：
- 让AI具备自驱力，通过现有工具创造新工具
- 实现自动调用执行机制
- 建立Hook触发系统，条件满足时自动执行相应工具
- 最终目标：打造类似"贾维斯"的智能后台助手

**重要性分析**：
- 真正解放用户双手
- 用户只需提供需求，AI负责操作执行
- 通过模型自驱的检测验证机制确保正确性

**参考实现**：Kiro、Qoder等项目的自动化机制

### 规划二：个性化与长期记忆
**功能描述**：
- 引入向量数据库（Vector Database）
- 记住用户偏好、习惯和历史对话关键信息
- 实现个性化响应（如"放我常听的歌"时知道具体指什么）

**重要性分析**：
- **生活场景**：长期记忆帮助学习用户习惯，提供个性化体验
- **工作场景**：记住常用工具和操作偏好
- **注意事项**：编程场景可能不适合，避免记住错误操作

### 规划三：技术深化探索
**待学习融入的技术**：
- KV缓存优化
- Transformer架构深入
- 长上下文实现策略
- 更高效的向量检索机制

**价值**：这些技术将在项目发展过程中逐步融入，提升系统整体性能和智能化水平。
